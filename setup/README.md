# Setup

How to connect each tool of the kit to your agent. For what each tool is and which one to
pick, see the [main README](../README.md#whats-in-the-kit).

| Tool | Setup guide |
|---|---|
| 📄 Agent-friendly docs | Nothing to install: read or link the pages in [`docs/`](../docs/) |
| 🔗 llms.txt | [llms-txt.md](llms-txt.md) |
| 🧩 Agent Skill | [agent-skill.md](agent-skill.md) |
| 🔍 Docs MCP server | [docs-mcp-server.md](docs-mcp-server.md) |

These pages are for people setting up the kit. They are kept out of `docs/` on purpose:
everything under `docs/` is published to agents through llms.txt, the Agent Skill and the
Docs MCP server.
